PRINT & TEXTILE DESIGN — GITHUB UPLOAD

1. Open the main folder of your GitHub repository (main branch).
2. Upload print-textile-design.html and print-textile-design-optimised.svg. Replace existing files with the SAME names.
3. Keep your existing prints folder in the main repository folder; it must contain print-01.webp through print-64.webp. These image files are NOT included in this ZIP because they were not uploaded in chat.
4. Commit changes and check the GitHub Actions deployment before testing the page.

This package is NOT a complete standalone copy of the carousel without the prints folder.

Do not upload the ZIP itself to your GitHub website; extract it first.
